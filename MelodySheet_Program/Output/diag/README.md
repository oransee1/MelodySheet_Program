# Output/diag — 개발용 화면 검증

제품 출력이 아니다. 단 검출, 세로줄, 커서 위치, 템포 변경 마디를 눈으로 보려고 저장한 PNG다.

이름 규칙 (대략):

| 접두 | 의미 |
|---|---|
| `page_NN_systems.png` | 그 페이지에서 찾은 단 |
| `page_NN_barlines.png` | 세로줄 |
| `heads_page_NN.png` | 음머리 후보 |
| `verify_page_NN.png` | 페이지 전체 확인 |
| `cursor_mNN.png` | 그 마디에서 커서 |
| `f1080_*` | 1080p 프레임 샘플 (시작, 템포 마디, 끝) |
| `fix*` / `fix2*` / `fix3*` | 스크롤·첫 마디 스캔을 고치며 남긴 비교 컷 |

코드를 고친 뒤 “단이 오선 단위로 쪼개졌는지”, “1단 첫 세로줄이 음자리표에 붙었는지”를 이 그림과 비교하면 된다.

여기에 검사 스크립트(`.py`)를 잠깐 두었다가 지운 적이 있다. 남는 산출물은 이미지뿐이다. 회귀 테스트로 쓰지 말고, 엔진 함수를 직접 호출해라.
