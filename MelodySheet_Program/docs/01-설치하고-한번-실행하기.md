# 01. 설치하고 한 번 실행하기

영상을 처음부터 만들 필요는 없다. 먼저 **시계 숫자가 기준 곡과 같은지**만 확인한다.

## 폴더

터미널을 **안쪽** `MelodySheet_Program` 으로 옮긴다. 바깥 저장소 루트에서 `python main.py` 를 치면 `engine` 을 못 찾는다.

```text
cd MelodySheet_Program
```

지금 이 문서가 있는 `docs/` 의 한 단계 위가 그 폴더다.

## 패키지

```text
python -m pip install -r requirements.txt
```

영상이 필요하면 ffmpeg도 PATH에 있어야 한다. 없어도 아래 검사 스크립트는 된다.

## 최소 확인 (영상 없이)

```text
python docs/inspect_timeline.py
```

성공하면 대략 이렇게 나온다.

```text
ok  마디 90
ok  music_end 202.723s
ok  마디1 템포 115
ok  마디40 템포 68
ok  마디50 템포 100
ok  마디61 템포 136
ok  마디77 템포 107
ok  마디1 길이 2.087s
```

한 줄이라도 `FAIL` 이면 입력 경로가 다르거나 XML을 못 읽은 것이다. [07-막혔을-때.md](07-막혔을-때.md)로 간다.

## 창을 띄우려면

같은 폴더에서:

```text
python main.py
```

뜨는 경로가 `InputData/오늘날짜/Input01` 이면 그 세트를 쓴다. 오늘 폴더가 비어 있으면 찾아보기로 `InputData/2026-08-14/Input01` 을 고른다.

전체 영상은 `python test_render.py` 다. 몇 분 걸리고 ffmpeg가 필요하다. 처음 하루는 `inspect_timeline.py` 만으로 충분하다.

## 이 단계에서 만지지 말 것

`sync_manager.py`, `score_layout.py` 를 아직 고치지 않는다. 숫자가 맞는데 화면이 이상하면 4장 이후로 간다.
