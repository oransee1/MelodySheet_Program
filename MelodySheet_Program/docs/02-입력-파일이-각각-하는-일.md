# 02. 입력 파일이 각각 하는 일

기준 세트: `InputData/2026-08-14/Input01/`

같은 이름에 확장자만 다르다. 프로그램은 이 옆 파일(사이드카)을 찾아 역할을 나눈다.

## 한 줄 비유

악보 영상을 만들려면 **어디에 그릴지**와 **언제 움직일지**가 둘 다 필요하다.

- PDF = 지도 (어디)
- MusicXML = 시계 (언제, 무슨 음으로 적혀 있나)
- MIDI = 어떤 연주자가 실제로 친 기록. 시계로 쓰면 이 곡에서는 빗나간다
- MP3 = 스피커로 나갈 소리
- LY = PDF를 그린 조판 소스. 시계 보조

## 왜 MIDI로 커서를 만들면 안 되나

직접 확인해 볼 수 있다. 첼로 첫 음은 악보 마디 14, 기보 시각 약 27.65초, 음이름은 G3(번호 55)다. 같은 음 MIDI는 약 29.72초에 있다. **약 2.07초 늦다.**

끝으로 갈수록 이 차이가 줄어든다. 일정한 딜레이가 아니므로 “MIDI에서 2초를 빼면 된다”도 틀린다.

그래서 커서는 XML 마디 길이로 움직이고, MIDI는 “그 성부가 그 음을 쳤는지” 검사에만 쓴다.

## 역할 표

| 파일 | 없어도 영상이 나오나 | 없으면 생기는 일 |
|---|---|---|
| pdf + mp3 | 필수 | 생성 불가 |
| musicxml | 거의 필수 | 마디 초가 부정확. 성부 감사 불가 |
| mid | 권장 | 감사 파일이 “MIDI 없음” |
| ly | 있으면 좋음 | XML이 있을 때는 보조만 |
| gp5 | 불필요 | 사람이 Guitar Pro로 볼 때만 |
