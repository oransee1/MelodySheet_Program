# 03. 마디 시계를 손으로 계산하기

커서가 “지금 몇 번째 마디인가”를 알려면 각 마디가 **몇 초에 시작해서 몇 초 동안인지**가 필요하다.

## 왜 이 수식인가

템포 115는 “1분에 4분음표 115개”다.

- 4분음표 1개 길이 = `60 / 115` 초 ≈ **0.5217초**
- 이 곡은 4/4 = 마디마다 4분음표 4개
- 한 마디 길이 = `4 × 60 / 115` ≈ **2.087초**

코드 (`score_timeline.py`):

```text
quarters = beats * (4 / beat_type)     # 4/4 → 4
dur = quarters * (60 / tempo)          # 4 * 60 / 115
```

`beat_type`이 4가 아닌 곡이면 `4/beat_type` 이 4분음표 개수로 환산한다. 3/4면 4분음표 3개.

## 이 곡에서 검산

| 마디 | BPM | 한 마디(초) | 그 마디 시작(초) |
|---|---|---|---|
| 1 | 115 | 2.087 | 0.000 |
| 2 | 115 | 2.087 | 2.087 |
| 40 | 68 | 3.529 | (1~39를 115로 더한 뒤) |
| 50 | 100 | 2.400 | |
| 61 | 136 | 1.765 | |
| 77 | 107 | 2.243 | |
| 90 끝 | 107 | | **202.723** |

시작 시각은 앞 마디 길이를 누적한 값이다. 템포가 바뀌는 마디부터 새 BPM을 쓴다.

확인:

```text
python docs/inspect_timeline.py
```

`music_end 202.723s` 와 마디 1 길이 `2.087s` 가 나와야 한다.

## 함수가 받는 것 / 주는 것

`build_score_timeline(musicxml_path, lilypond_path, midi_path)`

- 입력: 파일 경로 세 개 (없는 것은 `None`)
- 출력: `ScoreTimeline`
  - `n_measures` → 90
  - `music_end` → 202.723
  - `measures[i].start_sec`, `.duration_sec`, `.tempo_bpm`

`timeline.measure_at(27.65)` → 대략 마디 14 근처 (0부터 세는 인덱스와 번호 `number`를 헷갈리지 말 것. `measures[k].number` 가 악보 마디 번호다).

## 자주 하는 실수

1. **MIDI 노트 시각으로 마디를 자른다.** 연주는 늦다.
2. **음원 209.9초를 90으로 나눈다.** 템포가 다섯 번 바뀐다. 균등 분할이 아니다.
3. **XML 없이 MIDI만 넣고 템포가 하나라고 착각한다.** Klangio MIDI는 메타 템포를 안 바꾸는 경우가 많다.
