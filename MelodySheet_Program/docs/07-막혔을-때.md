# 07. 막혔을 때

증상으로 연다. 코드를 처음부터 다시 읽지 말 것.

## `inspect_timeline.py` 가 파일을 못 찾는다

- 현재 폴더가 안쪽 `MelodySheet_Program` 인가.
- `InputData/2026-08-14/Input01/Sunday Slow Motion.musicxml` 이 있는가.
- 파일 이름 띄어쓰기·확장자 `.musicxml` 을 확인한다.

## 마디 수가 90이 아니다

- XML이 아니라 다른 곡을 읽었다.
- `build_score_timeline` 에 xml 경로가 `None` 이라 LilyPond/MIDI로 떨어졌다. 로그의 `source=` 를 본다.
- XML 네임스페이스를 안 지웠다. 이 프로젝트는 `_strip_xmlns` 로 한 번 제거한다.

## music_end 가 202.7이 아니고 209.9에 가깝다

음원 길이를 시계로 썼다. XML 템포 누적이 아니다.

## 템포가 내내 115다

`<sound tempo="...">` 를 안 읽었다. 마디 40·50·61·77에 값이 바뀐다. `inspect_timeline.py` 가 그 네 줄을 FAIL로 찍는다.

## 창은 뜨는데 생성이 곧 죽는다

- ffmpeg 없음 → 영상만 실패. 감사 txt는 이미 써 있을 수 있다.
- PDF 경로가 Sample만 있고 xml이 없으면 레이아웃은 되고 성부 감사가 비다.

## 커서가 한 오선만 따라간다

단 검출이 오선 단위로 쪼개졌다. `merge_gap`(약 0.70in) 과 머리·바닥 crop을 본다. [04](04-PDF에서-단-찾기.md).

## 다음 페이지가 음을 다 듣기 전에 올라온다

`_scroll_offset` 의 페이지 분기가 마지막 마디 끝 0.4초보다 일찍 섞는다. `*_beat_audit.txt` 의 “페이지 유지”.

## 첼로 m23이 A2+F3 이다

`<chord/>` 음을 **지금 커서**에 넣었다. 직전 온셋에 붙여야 한다. A2+C3이 맞다.

## 베이스 첫 음이 한 옥타브 낮다

`clef-octave-change=-1` 을 MIDI에도 적용했다. 이 세트는 기보 높이 D3(50)끼리 비교한다.

## “음정 60%니까 구현이 절반만 됐다”

[06](06-감사-숫자-읽는-법.md). LCS와 가방을 같이 본다. 온셋 1%는 이 곡 MIDI의 성질이다.

## import 에러 `No module named engine`

바깥 폴더에서 실행 중이다. `cd MelodySheet_Program` (안쪽) 후 다시.
