# 학습 경로 (초심자용)

루트 README는 설계 명세서다. 여기는 **한 걸음씩 따라 하기**다.

가정하는 것: 터미널에서 `python` 을 실행해 본 적 있다. `pip install` 을 해 본 적 있다.  
가정하지 않는 것: MusicXML, MIDI 프로그램 번호, OpenCV, MoviePy를 안다.

## 이 경로가 가르쳐 주지 않는 것

- PyQt5 시그널/슬롯을 처음부터 설명하지 않는다. GUI는 경로만 넘긴다.
- ffmpeg 설치 화면을 OS마다 캡처하지 않는다. 없으면 영상만 실패하고 감사 파일은 남을 수 있다.
- `score_layout.py` 521줄을 한 줄씩 주석하지 않는다. 대신 “무엇을 넣으면 무엇이 나오는지”와 실패 증상을 적는다.

코드를 베끼기 전에 0→3까지 읽고 `inspect_timeline.py` 를 한 번 돌리는 것을 권한다.
